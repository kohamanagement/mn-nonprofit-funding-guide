# Minnesota Nonprofit Funding Guide

A free guide to grants and funders for any Minnesota nonprofit: a match finder, a funder map, a deadline calendar, a directory of about 695 funders, printable guides by cause, a guide to starting a nonprofit, an application kit and a glossary.

**Open the guide:** https://kohamanagement.github.io/mn-nonprofit-funding-guide/

The whole site is a single page, `index.html`. It is updated weekly.

**See something wrong or missing?** Open an issue in this repository.
